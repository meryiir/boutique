# Studio d’essayage

Le studio utilise désormais un configurateur 3D frontend avec sélection indépendante des hauts et pantalons, deux mannequins, 97 couleurs et rotation à 360°. Les modèles procéduraux sont simplifiés, sans fidélité de patron ni simulation physique du tissu.

Voir [la documentation actuelle du configurateur 3D](FITTING-3D.md), les [modèles GLB](3d-model-manifest.json) et les [captures de contrôle](screenshots/three-product-desktop.png).

Les [visuels préparés et leurs limites](FITTING-PREPARED.md) décrivent la version précédente et le mode de comparaison de face, conservé pour les sélections exactes disponibles.
